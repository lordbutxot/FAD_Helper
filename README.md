# F.A.D. Helper

F.A.D. Helper is a public-facing army list builder for the **F.A.D. (Fast and Dirty)** tabletop wargame. It helps players build legal armies faster with official data, clean UI, and real-time points.

## For players and clubs
- Build squads, characters, heavy weapons, snipers, psionics, and vehicles
- Automatic points calculation with live preview
- Official traits, properties, weapons, and armour
- Faction creation and list management
- Shareable lists for events and club play

## Why it exists
Manual list building is slow, error-prone, and hard to share. F.A.D. Helper keeps the rules accurate and the workflow fast—so players can focus on games, not spreadsheets.

## What’s included
- 6 unit builders
- 44 infantry traits + 26 vehicle properties
- 46 weapons + 8 armour types
- User accounts and saved lists
